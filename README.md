# DeGustte - Plataforma de Gestão para Bares e Restaurantes

Uma plataforma completa e inteligente para transformar a experiência dos seus clientes e impulsionar seu negócio.

## 🚀 Sobre o Projeto

DeGustte é uma solução digital que conecta tecnologia, hospitalidade e crescimento. Com ferramentas de gestão de cardápio digital, reservas, fila de espera e muito mais, sua empresa ganha inteligência para entender os clientes e tornar a gestão mais eficiente.

## ✨ Funcionalidades

- **Cardápio Digital** - Cardápios interativos com fotos e vídeos
- **Gestão de Reservas** - Controle total de reservas em tempo real
- **Fila de Espera** - Organize filas de forma automática
- **Gestão de Eventos** - Organize listas e eventos facilmente
- **Avaliações** - Colete feedback e melhore sua reputação
- **App Mobile** - Conecte clientes ao seu negócio

## 🌐 Como Hospedar Online

### Opção 1: GitHub Pages (Gratuito)

1. **Criar repositório no GitHub:**
   - Vá para https://github.com/new
   - Nome: `deguste-app`
   - Descrição: "Plataforma de Gestão para Bares e Restaurantes"
   - Deixe público

2. **Fazer push do código:**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: DeGustte platform"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/deguste-app.git
   git push -u origin main
   ```

3. **Ativar GitHub Pages:**
   - Vá para Settings do repositório
   - Desça até "Pages"
   - Em "Source", selecione "main branch"
   - Seu site estará em: `https://seu-usuario.github.io/deguste-app`

### Opção 2: Vercel (Recomendado - Gratuito e Rápido)

1. **Criar conta em Vercel:**
   - Vá para https://vercel.com
   - Faça login com sua conta GitHub

2. **Deploy:**
   - Clique em "New Project"
   - Selecione seu repositório `deguste-app`
   - Clique em "Deploy"
   - Seu site estará online em alguns segundos!

### Opção 3: Netlify (Gratuito)

1. **Ir para Netlify:**
   - Vá para https://netlify.com

2. **Fazer deploy:**
   - Arraste a pasta do projeto para a área de deploy
   - Ou conecte seu repositório GitHub
   - Pronto! Seu site está online

## 🌍 Adicionar Domínio Personalizado

Após hospedar seu site, você pode adicionar um domínio personalizado:

1. **Compre um domínio em:**
   - GoDaddy
   - Namecheap
   - Hostinger
   - Ou outro registrador de domínios

2. **Configure no seu host:**
   - **GitHub Pages:** Configure CNAME no repositório
   - **Vercel:** Vá para Settings > Domains
   - **Netlify:** Vá para Settings > Domain management

3. **Adicione os registros DNS:**
   - Copie os endereços DNS fornecidos pelo seu host
   - Adicione no painel do registrador do domínio
   - Aguarde 24-48 horas para propagação
